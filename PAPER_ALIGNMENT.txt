Scope and retained implementation choices:
The manuscript does not specify numerical EMA, warmup, weight decay, gradient
clipping, BCE positive weight, boundary kernel size, mixed precision, or all
backbone dimensions. Existing values remain; they are not asserted to be
paper-prescribed. The released binary RGB pipeline does not provide the
additional semantic/heterogeneous and robustness evaluation protocols.
Optional ablation flags remain available. In particular, the legacy loss API
weights FM and orbit terms separately; the correspondence above is for the
paper's default lambda_trans=1, not arbitrary non-default weight combinations.
Batch size is per process: choose 16/world_size when using distributed training.
